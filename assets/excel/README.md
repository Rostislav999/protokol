# Summary workbook

`summary.xlsx` is the built-in UBHP summary form, based on the user-provided
`0_Додаток зведена таблиця.xlsx` (source SHA-256
`b89bb99e11072713820b2a724f1fcc8fe256820dde93ca94a0dc71da2410aa86`).

The visible sheet, headers, cell styles, theme, column widths, table, protection,
validation lists, margins and page settings retain the supplied form's layout.
The program fills D–N. O/P remain blank for the responsible person's review.

The distributed form contains no protocol records. The hidden source-specific
service identifier, saved local directory, author metadata and printer-specific
binary settings were removed. The hidden sheet retains only the validation
choices used by the form. Each export uses a fresh copy of this workbook.
